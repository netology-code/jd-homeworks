## Инструкция по выполнению домашнего задания

1. Пишите код в IDE (например [OpenIDE](https://openide.ru/)). [Инструкция по установке IDE](https://github.com/netology-code/jspr-homeworks/blob/master/idea-installation.md). <br> Среда разработки IDE удобна в работе над проектами: есть подсказки в коде и отладка.
2. Опирайтесь на принятый [стиль оформления кода](https://github.com/netology-code/codestyle/blob/master/java/README.md).
3. Готовый код и другие материалы необходимо загрузить в специально созданный для данного домашнего задания репозиторий на сайте [github.com](https://github.com/).
4. На сайте [github.com](https://github.com/) найдите только что созданный репозиторий. Перейдя в репозиторий, нажмите на зеленую кнопку CODE и скопируйте появившуюся ссылку.
5. В личном кабинете на сайте [netology.ru](https://netology.ru/) в поле комментария к домашней работе вставьте скопированную ссылку и отправьте работу на проверку.

*Никаких файлов прикреплять не нужно.*
